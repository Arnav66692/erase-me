# Third-party licenses

## Optional local CAPTCHA tools (not bundled)

The web connector invokes separately installed Tesseract (Apache-2.0), whisper.cpp
(MIT), and FFmpeg (build-dependent license). No upstream binaries, trained OCR data,
or speech-model weights are included in this repository. These are optional runtime
dependencies, not code relicensed under the repository's MIT license. See
[local CAPTCHA setup](docs/LOCAL_CAPTCHA.md) for upstream sources and installation.

Erase Me reuses data from these MIT-licensed projects. Their license texts are reproduced below as the MIT License requires. See `skills/erase-me/references/SOURCES.md` for exactly what was taken and from which commit.
