Download companion
  1. Extract the ZIP into a folder you will keep.
  2. Open Chrome’s extensions page at chrome://extensions. Turn on Developer mode.
  3. Choose Load unpacked, then select the extracted folder containing manifest.json.
  4. Open the companion’s toolbar icon. Choose Enable broker forms and accept access to the eleven listed sites.
  5. Refresh Erase Me. Choose Check companion, then start a broker action or choose Review form batch.
  6. Updating an older companion? Replace its extracted files with this download, then choose Reload on Chrome’s extensions page. The current companion is version 0.10.0.
