01 Your accounts

Used only to prevent connecting your personal account. This account will not be authorized.

Create a new Gmail account first if you do not have a separate one. Keep passwords and verification codes in Google’s own sign-in page.

Choose “Copy companion ID” in the Erase Me extension. A command copied from its popup fills this automatically.

02 Choose how to connect

Use the 16-letter app password Google creates, never your Google account password. This simpler option needs no Google Cloud project. Google requires 2-Step Verification and may restrict app passwords for some accounts. If unavailable, choose Google sign-in above. Erase Me does not enable 2-Step Verification for you.

Create an app password in the separate Google account · Google’s eligibility guide. Already connected with this method? Leave this empty to reuse it. A new or changed app password requires intentional replacement below.

The password goes only to this local process and its owner-only settings file. It never enters the hosted app, workspace backup or chat. Setup authenticates the exact separate Gmail username without opening messages.

Already connected on this computer? Leave this empty to reuse the matching account. For a new connection, select the Desktop client file from your Google Cloud project. It goes only to this local setup process and is removed after use.

How to get the Google connection file. A shared, publicly approved Google client is not included yet.

03 Connect once

Optional and off by default. Every email still needs an exact message review and its own approval in Erase Me. To add sending to an existing connection, also choose intentional replacement above. Unchecking this option does not revoke an existing sending permission. App passwords cannot be limited to read-only at Google; Erase Me enforces its selected action limits locally.

Setup reads no messages, sends no broker requests and installs no recurring work. Supported: Python 3.10+, macOS Chrome and Linux Chrome/Chromium.
